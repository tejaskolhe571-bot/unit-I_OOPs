## Unit I - Programs

This repository contains C++ programs based on the concepts covered in Unit I. Each program demonstrates a basic C++ programming or Object-Oriented Programming concept.

### Program 1: Basic Data Types

**File:** `program_1.cpp`

Demonstrates the use of basic data types such as `int`, `char`, and `float`.

### Program 2: If-Else

**File:** `program_2.cpp`

Demonstrates the use of the `if-else` selection statement.

### Program 3: Loop and Array

**File:** `program_3.cpp`

Demonstrates the use of arrays and `for` loops.

### Program 4: Functions

**File:** `program_4.cpp`

Demonstrates function declaration, function call, and function definition.

### Program 5: Class and Object

**File:** `program_5.cpp`

Demonstrates the basic concepts of Object-Oriented Programming using a class and object.

### Program 6: Constructor and Destructor

**File:** `program_6.cpp`

### Program 7: Static Member

**File:** `program_8.cpp`
